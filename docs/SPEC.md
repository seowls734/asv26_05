# 폐광의 기사 — 시즌 1 기획 명세

## 기본
- 내부 해상도 320×192, 타일 16px, 맵 높이 12줄, 고정 60fps.
- 체력 하트 5칸. 체력과 동전은 다음 스테이지로 이어진다.
- 점프: 초속 −6.5, 중력 0.36. 점프 후 10프레임 안에 W를 떼도 최소 높이(약 56px)는 보장한다.
- 검: 좌클릭 베기(대미지 1), 3초 차지 후 거대한 검(앞 3칸, 대미지 3, 금 간 바위·덤불 파괴).

## 진행: 보스 보상
처음에는 그냥 화살만 있다. 각 스테이지 끝 보스를 쓰러뜨리면 보물상자가 나오고, E로 열면 아래 순서로 하나씩 얻는다. 상자를 열면 출구가 열린다.

| 스테이지 보스 | 보상 |
|---|---|
| 1-1 킹 슬라임 | 얼음 화살 |
| 1-2 서리 예티 | 불 화살 |
| 1-3 박쥐 여왕 | 강화 활 (평타 쿨다운 16→9프레임, 화살 속도 ×1.2, 대미지 2, 과녁 매듭 끊기) |
| 1-4 유적의 와이번 | 전기 화살 |
| 1-5 바위 전갈 | 풀 화살 |
| 1-6 폭풍 그리폰 | 빛 화살 |
| 1-7 용암 웜 | 땅 화살 |
| 1-8 가시꽃 여왕 | 바람 화살 |
| 1-9 그림자 리치 | 활 차징 (우클릭 2초, 차지 쿨다운 4초) |
| 1-10 고대 돌골렘 | 시즌 1 클리어 |

스테이지를 다시 시작하면 그 스테이지에 처음 들어갈 때의 능력으로 돌아간다.

## 화살
| 속성 | 일반 | 차지 |
|---|---|---|
| 그냥 | 기본 | 초록 거대 화살: 관통 대미지 4, 바위·과녁 파괴, 블록 밀기 |
| 얼음 | 2초 빙결(넉백 없음), 물(10초)·용암(15초) 굳히기 | 얼음 가시 5칸 [1,2,3,2,1] 계단, 5초 |
| 불 | 3초 화상, 덤불·상자 점화, 횃불·등불 켜기, 얼음 녹이기 | 레드 드래곤이 날아와 화염 브레스 |
| 전기 | 3초 스턴+대미지, 발전기 | 낙뢰 3번 (유리 통과) |
| 풀 | 5초 속박, 흙에 나무 | 피 1/3 이하 적 → 나무 골렘 20초 / 그 위 → 흡혈 나무 |
| 빛 | 거울 반사, 수정·등불 | 적: 1.5초 구속 후 폭발(대미지 5) / 빈 곳: 작은 태양 15초 |
| 땅 | 큰 넉백, 상자·갈라진 바위 파괴 | 쏘는 순간 지진 + 맞은 곳에 용암 분출 |
| 바람 | 빠른 직선, 큰 넉백, 풍차 회전, 블록 밀기 | 연두색 거대 독수리, 모든 적 관통 |

## 스테이지
| 스테이지 | 주요 퍼즐 (그때까지 얻은 화살만 사용) | 잡몹 (땅 / 하늘) |
|---|---|---|
| 1-1 엘프의 숲 | 돌계단, 블록 밀기 압력판, 거대한 검 바위, 열쇠 문 | 슬라임·버섯 / 박쥐 |
| 1-2 얼어붙은 호수 | 호수 얼리기, 얼린 슬라임을 압력판 무게로, 광차 | 얼음 슬라임 / 얼음 박쥐 |
| 1-3 어둠의 갱도 (어두움) | 불로 등불 켜기, 덤불 태우기, 횃불 순서(달→해→별) | 광부 해골·슬라임 / 박쥐 |
| 1-4 용의 유적 | 강화 활로 과녁 매듭 → 도개교, 덤불, 얼음벽 녹이기 | 불도마뱀 / 독수리 |
| 1-5 바위 협곡 | 발전기와 전기 방벽, 발전기 세 개 | 바위 게·불도마뱀 / 독수리 |
| 1-6 바람의 절벽 | 흙에 나무를 키워 절벽 오르기 | 산양(돌진) / 하피(급강하) |
| 1-7 용암 동굴 | 용암 굳히기, 나무, 레버 거울, 거울 두 개 | 불 슬라임 / 마그마 박쥐 |
| 1-8 하늘 정원 | 땅 화살로 갈라진 벽, 받침을 부숴 블록 떨어뜨리기 | 가시꽃·버섯 / 벌 |
| 1-9 고대 신전 (어두움) | 풍차 문, 횃불 네 개(잎→별→달→해), 바람으로 블록 밀기, 풍차 거울 | 해골 궁수 / 유령 |
| 1-10 골렘의 심장 | 시험의 회랑: 얼음 계단, 젖은 덤불(드래곤), 하늘의 벼락, 그림자 벽 | 꼬마 돌골렘 / 수정 박쥐 |
