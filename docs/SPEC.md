## 2. 화면과 기본 규칙
- 내부 해상도 320×192, 타일 16px, 맵 높이 12줄. CSS로 확대, image-rendering:pixelated.
- 고정 타임스텝 60fps. 한 번 눌림(P) 플래그는 step이 실제로 돈 뒤에만 지운다.
- 키는 e.code 기준으로 읽는다(한글 입력 상태에서도 작동).
- 상태 흐름: title → play → trans(페이드) → 다음 스테이지 또는 win. 체력 0이면 over.
- 폰트: Do Hyeon(제목·한글 UI), Noto Sans KR(본문), Silkscreen(영문 라벨).
- 다크 단일 테마. CSS에 [hidden]{display:none!important} 필수.

## 3. 조작
| 입력 | 기능 |
|---|---|
| A / D | 뒤로 / 앞으로 |
| W | 점프 (떼면 낮게 = 가변 점프) |

| 우클릭 | 마우스 방향으로 활 발사 (쿨다운 16), 우클릭 메뉴 막기 |

모바일 (hover:none, pointer:coarse일 때 터치 버튼 표시)
- 버튼: ◀ ▶ / 점프 / 대쉬 / E / 속성 / 활 / 검
- 검: 길게 누르면 차지.
- 활: 누른 채 끌면 조준(14px 이상 끌었을 때), 점선 궤적 미리보기 표시. 떼면 발사, 끌지 않고 떼면 정면.
- 세로 화면: 캔버스 아래에 버튼.
- 가로 화면(높이 ≤560px): [이동 패드][캔버스][액션 패드] 3열 그리드.

- 버튼에 touch-action:none, 길게 누르기 메뉴 방지, 활 버튼은 setPointerCapture.
- 화면 아래에는 조작표와 속성표(속성 / 맞은 적 / 맵에서 쓰기)를 둔다.

## 4. 플레이어 (엘프)
- 히트박스 10×14, 스프라이트 12×16. 금발, 뾰족한 귀, 초록 튜닉, 갈색 벨트.
- 다리 프레임: idle / run1 / run2 / jump / fall
- 물리: 중력 .36, 최대 낙하 7, 점프 −6.5, 이동 1.7 (지면 가속 .35, 공중 .2), 코요테 6f, 점프 버퍼 7f.
- 차지 중(15f 초과) 이동 속도 ×0.55.
- 피격: 무적 70f, 넉백(가로 2.6, 세로 −3.4), 화면 흔들림 7, 히트스톱 4f.
- 가시·물·낙사: 체력 1 감소 후 lastSafe에서 부활.
  lastSafe는 양발 아래가 모두 SAFE일 때만 갱신한다.
  (얼음·상자 위는 저장하지 않음 → 녹은 뒤 무한 부활 반복 방지)
- 체력 5칸, 하트 아이템 +2. 체력과 동전은 다음 스테이지로 이어진다.

## 5. 검
일반 베기
- 14f 유지, 판정 구간은 남은 프레임 12~5.
- 판정: 앞쪽 22px, 높이 = 키+6. 대미지 1, 넉백 2.6. B(상자)를 부숨.
거대한 검
- 180f 차지가 끝나면 머리 위에 큰 검이 나타나고, 차지 바가 깜빡이고, 토스트를 띄운다.
- 떼면 22f 동안 공격, 판정 구간은 남은 프레임 18~8.
- 판정: 앞쪽 52px(약 3칸), 위로 26px. 대미지 3, 넉백 4.
- B, R, T, b를 부순다. 초승달 픽셀 이펙트, 화면 흔들림 8.
공통
- 얼어 있는 적을 검으로 치면 대미지 +1, 얼음이 깨짐.
- 공격 한 번에 같은 적은 한 번만 맞는다(hitSet).

## 6. 활과 6속성
화살 공통
- 속도 5.6, 중력 .06, 한 프레임에 서브스텝 2번으로 충돌 검사, 수명 110f.
- 벽에 맞으면 45f 꽂혀 있다가 사라짐. 적에게 맞으면 대미지 1 + 속성 효과.
- 속성 화살은 날아가며 그 색의 꼬리 파티클을 남긴다.

| 속성 | 색 | 맞은 적 | 맵 기믹 |
|---|---|---|---|
| 그냥 | #e8e2d0 | 대미지만 | 없음 |
| 얼음 | #8fe3ff | 2초(120f) 빙결: 정지, 접촉 피해 없음 | 물(w)에 맞으면 그 열의 가장 위 물줄에서 좌우 ±2칸을 얼음(i)으로. 600f 뒤 녹음, 녹기 90f 전부터 깜빡임 |
| 불 | #ff7a2a | 3초(180f) 화상: 60f마다 1대미지 | T·B 점화 → b. 70f 뒤 사라지고 40f 시점에 상하좌우로 번짐. 상자였으면 70% 확률로 동전. 얼음은 녹임 |
| 전기 | #ffe14d | 3초 스턴 + 60f마다 1대미지, 접촉 피해 없음 | Z를 켜면 z, ±18열 안의 G가 모두 사라짐 + "방벽이 열렸다" |
| 풀 | #6fdc5a | 5초(300f) 속박: 이동 불가, 덩굴 표시 | 흙(o)에 맞으면 나무가 자람(7번). 일반 땅에 쏘면 처음 한 번만 안내 |
| 빛 | #fff6c8 | 대미지 | 꽂히면 480f 동안 반경 60의 빛. 등불(L) 윗부분에 맞히면 영구 점등 |

- 상태이상 표시: 빙결은 하늘색 틴트와 얼음 박스, 스턴은 노란 깜빡임과 스파크, 화상은 불꽃 파티클, 속박은 바닥 덩굴.
- 물에 들어간 화살: 얼음은 얼리고, 나머지는 물보라를 내고 사라진다.

## 7. 나무 성장 (풀 화살 + 흙)
- 맞은 흙 바로 위 칸이 '.'일 때만 자란다.
- 위로 k = 0~6까지 쌓고, 막힌 칸을 만나면 멈춘다. 4f마다 한 칸씩.
  - k 짝수(0, 2, 4): 줄기 y (통과, 장식)
  - k 홀수(1, 3, 5): 잎 발판 f 3칸 (tx−1, tx, tx+1), 일방통행
  - k = 6: 수관 c (장식)
- 줄기 좌표를 S.trunks에 저장해서, 잎 발판 아래에도 줄기를 그린다.

## 8. 타일 범례

## 10. 광차 (스테이지 2)
- 레일 위에서만 움직임. 크기 22×12, 가속 .1, 최고 속도 2.4.
- E로 타기/내리기(내릴 때 위로 살짝 튀어오름). 탄 상태에서 W를 누르면 −6.5로 뛰어내림.
- 위에서 광차 안으로 떨어지면 자동 재탑승. 단, 내린 직후 20f 동안은 자동 탑승하지 않음.
- 탄 상태에서도 검과 활은 쓸 수 있고, 대쉬는 쓸 수 없다.

## 13. 튜토리얼 문구
- 플레이어가 해당 열을 넘으면 한 번만, 토스트 큐로 3.4초 동안 표시한다.
- 마지막 입력이 터치였으면 ctrl = {atk:'검 버튼', bow:'활 버튼(끌어서 조준)', el:'속성 버튼'},
  아니면 {atk:'좌클릭', bow:'우클릭(마우스 조준)', el:'F 키'}.
- 문구:
  - atk: "{atk}로 베기 · {bow}로 활 쏘기"
  - elem: "{el}로 화살 속성을 바꿀 수 있어요"
  - grass: "갈아놓은 흙에 풀 화살을 쏘면 나무가 자라요"
  - fire: "가시덤불은 불 화살로 태우세요"
  - giant: "{atk}을 3초 누르고 떼면 거대한 검! 금 간 바위를 부숴요"
  - ice: "얼음 화살로 호수를 얼려 건너세요 (10초 뒤 녹아요)"
  - elec: "전기 화살로 발전기를 켜면 방벽이 열려요"
  - cart: "광차에 다가가 E로 타세요"
  - light: "빛 화살로 등불을 밝히세요. 어둠 속엔 함정이 있어요"
  - mix: "이제 배운 속성을 모두 써야 해요"

## 14. HUD · UI · 소리
캔버스 HUD
- 왼쪽 위: 하트 5칸, 동전 ×N, 열쇠 ×N (3x5 비트맵 숫자)
- 오른쪽 위: 스테이지 코드
- 위 가운데: 6속성 화살 아이콘, 선택된 칸은 테두리
- 상호작용 대상 위에 흔들리는 [E] 키캡, 차지 중에는 머리 위 게이지
DOM
- 속성 배지 "불 화살"(속성 색)
- 하단 토스트 (now=true는 즉시 표시, 아니면 큐)
- 시작·게임오버·클리어 오버레이 (클릭·탭·키로 진행)
소리
- WebAudio 오실레이터 효과음:
  jump, slash, bow, coin, hurt, dash, door, hit, pick, crate, kill, swap, giant, charged, freeze, fire, zap, grow, light, splash
- 첫 사용자 입력 이후에만 오디오를 켠다.

## 16. 완료 확인 체크리스트
- [ ] 1-1: 흙에 풀 화살 → 나무 발판으로 절벽 위 → 불 화살로 덤불 제거 → 열쇠 → 거대한 검으로 바위 → 철문 → 출구
- [ ] 1-2: 얼음 화살로 호수 건너기 → 발판의 열쇠 → 전기 화살로 발전기 → 방벽 열림 → 광차로 가시 구덩이 통과 → 철문 → 출구
- [ ] 1-3: 빛 화살로 등불 점등, 덤불·흙·호수·발전기·바위를 모두 거쳐 클리어 화면까지
- [ ] 상태이상 지속 시간: 빙결 2초, 화상 3초, 전기 3초+스턴, 속박 5초
