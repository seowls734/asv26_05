# 폐광의 기사 — 시즌 1·2

엘프 기사가 그냥 화살 하나로 시작해, 스테이지마다 보스를 쓰러뜨리고 보물상자에서 새 화살과 힘을 얻으며 10개 스테이지를 지나는 2D 횡스크롤 도트 액션 웹게임입니다. 시즌 1을 깨면 엔딩 뒤에 초원에서 마계로 가는 시즌 2(스테이지 12개, 마왕까지)가 이어집니다.

## 실행
- `index.html`을 더블클릭하면 바로 실행됩니다. 서버가 필요 없습니다.
- 배포할 때는 `index.html`, `css/`, `js/` 폴더를 그대로 올리면 됩니다.
- 외부에서 불러오는 것은 Google Fonts뿐입니다. 인터넷이 없어도 기본 글꼴로 실행됩니다.
- 스크립트를 불러오거나 실행하다 에러가 나면 게임 화면에 빨간 글씨로 내용이 나옵니다.

## 조작
| 입력 | 기능 |
|---|---|
| A / D (← →) | 뒤로 / 앞으로 |
| W (↑, 스페이스) | 점프 (짧게 눌러도 약 3.5칸, 길게 누르면 더 높이) |
| Q | 대쉬 (무적) |
| E | 줍기 · 문 · 광차 · 레버 · 석판 · 골렘 명령 · 보물상자 |
| 좌클릭 | 검 (3초 누르고 떼면 거대한 검) |
| 우클릭 | 활 (활 차징을 얻으면 2초 누르고 떼서 차지 화살) |
| F / 1~8 | 화살 속성 바꾸기 |
| R / M | 스테이지 다시 시작 / 소리 |

휴대폰과 태블릿에서는 화면에 터치 버튼이 나옵니다.
- ◀ ▶ 는 손가락을 떼지 않고 옆으로 미끄러뜨리면 방향이 바로 바뀝니다.
- 가로 화면에서 게임이 가장 크게 보입니다. 브라우저 메뉴의 "홈 화면에 추가"로 설치하면 주소창 없이 전체 화면으로 실행됩니다.

## 파일 구조
모든 js 파일은 ES Modules가 아닌 일반 `<script>`입니다. `index.html`에 적힌 순서대로 같은 전역 범위에서 실행되므로, **새 파일을 만들면 `index.html`의 script 목록에 알맞은 순서로 추가**해야 합니다.

## 검수용 바로 시작
주소 뒤에 `?level=N`을 붙이면 N번째 스테이지에서 바로 시작합니다. 능력은 그 스테이지에 처음 들어갈 때와 같습니다.
- `index.html?level=3`: 1-3 어둠의 갱도
- `index.html?level=11`: 2-1 바람의 초원 (시즌 2, 22까지)
- `index.html?ending`: 시즌 1 엔딩만 보기
- `index.html?level=10`: 1-10 골렘의 심장

## 개발용 디버그 훅
브라우저 콘솔(F12)에서 쓸 수 있습니다.
- `__dbg.loadLevel(4)` — 1-5로 바로 이동 (0부터 시작)
- `__dbg.warp(30)` — 30번째 칸으로 순간이동
- `__dbg.setGot(9)` — 보상 9개를 모두 얻은 상태로
- `__dbg.hitBoss(10)` — 보스에게 대미지 10
