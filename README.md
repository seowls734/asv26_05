# 폐광의 기사

엘프 기사가 여섯 속성의 화살과 검으로 숲, 얼어붙은 호수, 어두운 갱도를 지나가는 2D 횡스크롤 도트 웹게임입니다.
빌드 도구와 외부 라이브러리, 이미지 파일 없이 일반 `<script>`와 Canvas로 만들었습니다(도트는 코드로 그림, 글꼴만 Google Fonts).

## 실행 방법

**`index.html`을 더블클릭하면 바로 실행됩니다.** 서버가 필요 없습니다.

로컬 서버는 선택 사항입니다. 휴대폰으로 해 보거나 다른 기기에서 열 때만 쓰면 됩니다.

- **npx serve** (선택): 프로젝트 폴더에서 아래 명령을 실행한 뒤, 터미널에 나온 주소(보통 http://localhost:3000)를 엽니다.
  ```
  npx serve .
  ```
- **VS Code Live Server** (선택): `index.html`을 연 상태에서 오른쪽 아래의 "Go Live"를 누릅니다.

휴대폰으로 해 보려면 서버를 켠 뒤 같은 와이파이에서 PC 주소(예: `http://192.168.0.10:3000`)로 접속하세요.

스크립트를 불러오거나 실행하다 에러가 나면 화면 가운데에 빨간 글씨로 내용이 나옵니다.

## 조작

| 입력 | 기능 |
|---|---|
| A / D | 뒤로 / 앞으로 |
| W | 점프 (짧게 누르면 낮게 뜀) |
| Q | 대쉬 (잠깐 무적, 공중에서 1회) |
| E | 열쇠·하트 줍기, 철문 열기, 출구, 광차 타기/내리기 |
| 좌클릭 | 검 베기 |
| 좌클릭 3초 유지 후 떼기 | 거대한 검 (금 간 바위 파괴) |
| 우클릭 | 마우스 방향으로 활 쏘기 |
| F / 1~6 | 화살 속성 바꾸기 / 직접 고르기 |
| R / M | 스테이지 다시 시작 / 소리 끄기·켜기 |

키는 위치 기준으로 읽기 때문에 한글 입력 상태에서도 작동합니다.

**휴대폰**: 화면 아래(가로 화면이면 양옆)에 버튼이 나옵니다.
- ◀ ▶ 이동 / 점프 / 대쉬 / E / 속성 / 활 / 검
- **검**: 길게 누르면 차지되고, 떼면 거대한 검이 나갑니다.
- **활**: 누른 채 끌면 조준하고 점선으로 궤적을 보여 줍니다. 떼면 발사합니다. 끌지 않고 떼면 정면으로 쏩니다.
- **◀ ▶**: 손가락을 떼지 않고 옆으로 미끄러뜨리면 방향이 바로 바뀝니다.
- 가로 화면에서 게임이 가장 크게 보입니다. 브라우저 메뉴의 "홈 화면에 추가"로 설치하면 주소창 없이 전체 화면으로 실행됩니다.

## 화살 속성

| 속성 | 맞은 적 | 맵에서 쓰기 |
|---|---|---|
| 그냥 | 대미지만 | — |
| 얼음 | 2초 빙결 | 물을 얼려 발판으로 (10초 뒤 녹음) |
| 불 | 3초 화상 | 가시덤불·상자를 태움, 얼음을 녹임 |
| 전기 | 3초 스턴 + 대미지 | 발전기를 켜서 전기 방벽 해제 |
| 풀 | 5초 속박 | 갈아놓은 흙에 나무를 키워 발판으로 |
| 빛 | 대미지 | 주변을 밝힘, 등불을 켬 |

## 스테이지

1. **1-1 엘프의 숲**: 풀, 불, 거대한 검
2. **1-2 얼어붙은 호수**: 얼음, 전기, 광차
3. **1-3 어둠의 갱도**: 빛, 지금까지 배운 속성 모두

## 검수용 바로 시작

URL 뒤에 `?level=N`을 붙이면 해당 스테이지에서 바로 시작합니다. 더블클릭으로 연 경우에도 주소창 끝에 붙이면 됩니다.

- `index.html?level=2`: 1-2 얼어붙은 호수
- `index.html?level=3`: 1-3 어둠의 갱도

브라우저 콘솔에서 `window.__game`(`{S, loadLevel}`)이나 전역 `G`로 상태를 보거나 스테이지를 불러올 수 있습니다.

## 폴더 구조

```
index.html, css/style.css
js/main.js config.js state.js input.js audio.js ui.js
js/gfx/      sprites.js tiles.js font.js background.js lighting.js renderer.js
js/world/    tiledefs.js level.js physics.js effects.js
js/entities/ player.js enemies.js arrows.js cart.js pickups.js particles.js
js/data/     elements.js levels.js hints.js
```

각 파일은 즉시 실행 함수로 감싸서 공개할 것만 전역 `G`에 붙입니다(예: `G.physics`, `G.player`). 불러오는 순서가 중요하므로 `index.html` 아래쪽의 `<script>` 순서를 지켜야 합니다.

명세는 `docs/SPEC.md`, 모듈 사이의 약속은 `docs/CONTRACT.md`에 있습니다.
